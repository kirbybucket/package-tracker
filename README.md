# 📦 Package Tracker

Sistema de seguimiento de paquetes con notificaciones WhatsApp.

## 🚀 Características

- ✅ Seguimiento automático de múltiples paquetes
- ✅ Notificaciones por WhatsApp cuando el paquete llega
- ✅ Gestión de paquetes desde interfaz de consola
- ✅ Almacenamiento de historial en Firestore
- ✅ Configuración personalizable
